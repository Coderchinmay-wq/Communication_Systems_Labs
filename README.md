## About

This repository documents the experiments performed as part of the
Communication Systems Laboratory (25EECP304).

The repository contains:

- Circuit implementations
- Proteus simulations
- Theoretical concepts
- Circuit diagrams
- Design calculations
- Experimental observations
- Oscilloscope waveforms
- Results
- Laboratory setup photographs
- Conclusions

The objective is to maintain a complete technical record of the
Communication Systems Laboratory throughout the semester.

## Laboratory Workflow

For every experiment, the following workflow is followed:

1. Study the theoretical concept
2. Design the circuit
3. Simulate the circuit in Proteus
4. Implement the circuit on a breadboard
5. Test the circuit using laboratory equipment
6. Observe waveforms using the oscilloscope
7. Record measurements
8. Perform calculations
9. Compare theoretical and practical results
10. Document the experiment
